# Design Thinking Project

A practical Design Thinking project that demonstrates the full process of research, ideation, prototyping, testing, and problem-solving.

## Project Overview
This project follows the Design Thinking methodology to understand a real-world problem, research user needs, generate ideas, and develop a potential solution.

## Project Structure
- `01-Research-Plan` – Research planning and user insights
- `02-design-thinking` – Ideation, prototyping and solution development stages

## Process Followed
1. **Empathize** – Understanding the users and their needs
2. **Define** – Clearly stating the problem
3. **Ideate** – Generating possible solutions
4. **Prototype** – Creating a simple version of the solution
5. **Test** – Gathering feedback and refining the idea

- Research & analysis
- Creative thinking
- Structured documentation
- Design Thinking methodology
