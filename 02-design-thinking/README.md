# Weather-Resistant Fast-Food Stall

This project is a Design Thinking project focused on helping small fast-food vendors continue operating and serving customers during bad weather.

## Design Thinking Process

The project includes:

- Research
- Key insights
- How Might We statement
- Ideation
- Solution selection
- Low-fidelity prototype
- Testing
- Mid-fidelity prototype
- Feedback and improvements
- Expected impact

## Proposed Solution

A foldable, weather-resistant fast-food stall designed to protect vendors, food, equipment and customers from rain and harsh weather.

The solution includes a foldable design, waterproof roof, weather-resistant side panels, protected customer seating and power-support features. 0
